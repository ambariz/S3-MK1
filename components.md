## Cube
### Controller
- ESP8266 D1 Mini
(we are using D1 mini because it's small and fits perfectly inside cube)

### Motion
- mmWave sensor HLK-LD2410-AA

### Vibration
- SW-420 Vibration Sensor

### Angle / Tilt
- MPU6050
(this sensor have 3 axis accelerometer and Gyro)

### Light
- LDR

### Temperature
- DHT11

### Humidity
- DHT11
